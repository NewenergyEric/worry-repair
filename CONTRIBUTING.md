# Contributing / 参与改进

Useful contributions include clearer interactions, keyboard access, responsive layout fixes and English/Chinese translation corrections. Describe the situation, what you expected and what you observed. For a visual issue, include the language and viewport size.

1. Install with `npm ci` and run `npm run dev`.
2. Keep card content and UI changes consistent in both languages.
3. Run `npm run check` and `npm run build`.
4. If adding a distributable file, add its explicit path to `public-files.json` and review the licence scope.
5. In the pull request, explain the change and the interactions you checked.

Keep the default demo at three cards (01, 08, 12). Do not contribute the private PDF collection, print assets, production projects, contact data, credentials or full website content dumps. If you add new examples, use material you have permission to share and discuss changing the sample scope first.

笔记与收藏仅在当前浏览器保存。修改相关功能时，请检查保存、重载、清空、撤销及键盘操作。不要在反馈里粘贴自己的私人练习笔记或他人的联系方式。

本仓库欢迎交互、无障碍、响应式布局和双语表达方面的改进。提交前运行检查与构建，说明改动及实际验证过的操作；新增文件时同步更新发布白名单。默认示例保留 01、08、12 三张卡，私有 PDF 与制作资料不纳入贡献范围。
