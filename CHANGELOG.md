# Changelog / 更新记录

## On main after 0.1.0 · 2026-10-13

The creator's story now opens both READMEs. A small looping introduction and still images let you meet the cards as you read: three everyday starting points, and a reminder that life was never single choice. The complete films are still one link away.

中英文介绍现在从创作者和身边人的故事讲起。轻量循环短片与配图陪你边读边逛：先看看三张日常工具卡，再给“人生，又不是单选题”留一点空间。完整影片仍可通过链接观看。

## 0.1.0 · 2026-10-13

It starts with a familiar afternoon: a cup on the desk, a blank note and something you keep meaning to do. The first GitHub release introduces Worry Repair through that small moment, in English and Chinese.

Read the story, watch the landscape film, then visit the [official website](https://anxietyfixer.lifeunltdco.com/) to find one idea you can try. Follow this repository's releases to hear about what comes next.

这一版，从一个熟悉的午后开始：桌上的水杯、空白的便签，还有那件一直想做的事。中英文故事与横版短片，陪你看看烦恼维修部怎样帮你找到今天可以试的一小步。

完整体验在[官网](https://anxietyfixer.lifeunltdco.com/)。选择 **Watch → Custom → Releases**，下次有新内容时，我们再见。

### For contributors / 供参与者参考

- A standalone React/Vite demo with three bilingual sample cards: 01, 08 and 12.
- Search, filters, read/practice tabs, browser-local notes and saved cards.
- A bilingual sample introduction, update log and GitHub release subscriptions.
- Eight finished films in English/Chinese and four aspect ratios, with music and no voiceover.
- MIT application code, separate content/media terms, and an explicit release file allowlist.

This release publishes the GitHub repository. It does not deploy changes to the official website. PDF collections and editable production sources remain private.

本次发布范围为 GitHub 仓库；官网未随此版本更新。PDF 卡包与可编辑制作源文件保持私有。
